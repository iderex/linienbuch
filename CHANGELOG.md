# Changelog

What changed between versions of this board, written for the reader who upgraded
and got a different number. The scheme, what each component means, and which
headings an entry sits under are in `docs/versioning.md` and are not restated
here.

## Nothing has been released

At the commit this file lands on there is no release and no tag:

    gh release list --repo iderex/linienbuch
    git ls-remote --tags origin

Both print nothing. `Cargo.toml` carries `version = "0.0.0"`, which is a
placeholder that lets a package exist rather than a version this scheme has been
applied to.

So the sections below are empty because there is nothing to put in them, not
because nothing has happened. What has happened is in the issues and in the
history, and this file does not restate it. A changelog reconstructed afterwards
from a history is a description of that history; this one starts here and is
kept with the work, which is the only way it says anything the history does not
already say better.
